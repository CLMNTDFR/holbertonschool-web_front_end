# Bootstrap

This project uses Bootstrap 4.4.1 (CSS via CDN) to build responsive layouts with containers, the grid system, components, and utilities.

## Requirements

- Bootstrap version 4.4.1
- Use the CDN version
- A README.md at the root of the project directory is mandatory

## Resources

- [Bootstrap](https://getbootstrap.com/docs/4.4/getting-started/introduction/)
