# Cookies and local storage

This project shows how to create cookies in Javascript, how to read them, and how the browser web storage works.

## Requirements

- Files use the `js` extension
- All files ends with a new line
- `src/index.js` stays empty, the Javascript goes in the HTML `<script>` tag
- A README.md at the root of the folder is mandatory
