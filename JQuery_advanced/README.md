# jQuery advanced

This project shows how to load jQuery from a CDN, create and modify DOM elements, handle clicks, and send AJAX queries.

## Requirements

- All files ends with a new line
- A README.md at the root of the folder is mandatory
- Scripts use type application/javascript when asked

## Resources

- jQuery CDN
- jQuery API Documentation
- Json server

## Tasks

0. Setup your dev environment: load jQuery slim from the CDN and check it in the console.
1. Creating a DOM element: build a paragraph with jQuery and append it to the body.
2. Creating multiple DOM elements at once: append a whole family table from one string.
