# JavaScript Advanced

This project covers lexical scoping, closures, the execution stack, binding, and callbacks in JavaScript.

## Requirements

- Files use the `.js` extension
- All files end with a new line
- A README.md at the root of the project directory is mandatory

## Resources

- Lexical scoping
- Closure
- Call stack
- Binding
- Callbacks

## Tasks

0. Lexical scoping and welcome message: nested `displayFullName` reads `fullName` from `welcome`.
1. Closure scope chain: nested `outer`, `inner`, and `inception` alerts.
2. Closure: `welcomeMessage` returns a function that alerts Welcome plus the name.
3. Closure and loops: each `studentSeat` closure keeps its own seat number.
4. Complex closure: `addBy` and `divideBy` return reusable math functions.
5. Changing DOM with closure: buttons switch Spooky, Dark, and Scream themes.
